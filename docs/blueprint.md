# **App Name**: EliteBlade

## Core Features:

- Client & Admin Authentication: Secure user login and registration for both clients and salon administrators, supporting email/password and social login options.
- Service Catalog Management: Administrators can add, edit, and remove salon services, including detailed descriptions, duration, and pricing.
- Barber Profile Management: Administrators can create and manage barber profiles, assign specialties, define individual working hours, and block out personal time off.
- Appointment Booking: Clients can browse available services, select a preferred barber, and book appointments for specific date and time slots from real-time availability.
- Personal Appointment Overview: Clients can view their upcoming and past appointments, with direct options to reschedule or cancel existing bookings.
- Admin Schedule Management & Dashboard: A comprehensive interface for administrators to view the entire salon schedule, manage barber availability, manually block time slots, and add new appointments. Also provides key performance metrics like daily revenue and new clients.
- AI-Assisted Service Description Tool: An AI-powered tool for administrators to generate creative and appealing descriptions for new or existing salon services, helping to attract more clients.

## Style Guidelines:

- Primary color: A sophisticated, warm gold (#FFBF00) to convey luxury and a premium feel. Converted from HSL(45, 100%, 50%).
- Background color: A very dark, desaturated amber-tinted grey (#15130F), visually aligned with the primary hue (HSL(45, 20%, 7%)), enhancing the dark theme.
- Accent color: A deep, rich brown-orange (#5C2D17), providing a warm contrast to the gold and evoking natural textures, converted from HSL(15, 50%, 30%).
- Body and headline font: 'Inter' (sans-serif), for a modern, objective, and clean aesthetic that matches the premium brand.
- Utilize 'Material Symbols Outlined' for all icons, employing both filled and outlined variations (wght: 400, opsz: 24) to maintain a modern and clear visual language. Key actions may use 'FILL' 1 for emphasis.
- Employ structured 'Bento Grid' layouts for main content areas and dashboards, with consistent spacing and a maximum content width for readability and responsiveness across all device sizes.
- Subtle, smooth 'ease-in-out' transitions for interactive elements like buttons and cards, incorporating hover effects (brightness, scale) and image transformations to enhance user engagement without distraction.
